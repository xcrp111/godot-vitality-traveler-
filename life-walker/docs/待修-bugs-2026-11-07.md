# 测试反馈 12 条（2026-11-07）

> 状态：✅ 已修 / 🚧 排查中 / ⬜ 待做

## 枪客

1. ✅ **嗜血裁决**：2A 附加的 8% 真伤在怪物无护甲时不生效（机制与描述不符）；另外"无枪势也能叠失衡""没打 1A 就能触发 3A 效果"。
   - 真伤改走新的 `Combat.TrueDamage`：无视减伤/暴击/破甲/吸血，也不再触发连携；数字用偏上的红色单独显示（原来和主伤害叠在同一像素，看着像「没生效」）。
   - 「没打 1A 就吃 3A」的真因是**空挥也推进连段**：`cs.spearCombo` 现在只在真正命中目标时推进，空挥清零，所以 3A 的必定暴击 / 叠满失衡必须先打中 1A、2A。
2. ✅ **破军追猎**：状态栏加了两条 chip：「追猎 · 普攻+55%」倒计时（`cs.next3aTimer`）和「击杀 xN · 攻+X%」常驻（`cs.killAtkStacks`，角标显示「常驻」）。
3. ✅ **固阵壁垒**：`Combat.GuardBlockBullet` 重做。固守期间子弹不掉血，**沿原弹道反向**生成玩家弹体打回去（2.5 倍伤害 + 失衡），反弹物只打敌人，不会结算到自己；冲锋波（shock）在固守期间也不再掉血。
4. ✅ **飞枪轮回**：折返段改成**追着角色飞回来**，接住时返还 2 秒掷枪冷却（`cooldowns[4] -= 2`），3 秒没接住自动消失。描述同步更新。
5. ✅ **奔突回锋**：角标现在只显示「还能放几次」——基础那 1 次在冷却期间不计入，所以回马枪冷却时角标从 2 变成 1，用完就消失。
6. ✅ **逐影千旋**：位移技能（突刺 / 疾退 / 换位 / 突进 / 瞬影）的残影改为跟随本体移动（`ph.follow`），复刻打在人真正冲到的位置；另外三段枪式本体没有直接伤害，残影不再凭空打出 3.4 倍技能伤害，改成单段 0.8 倍。

## 通用

7. ✅ **借势破斩**（剑客紫卡）：依赖旋刃横斩却能被刷出 → 已加入 `Config.ClassBuffSkills.swordsman`：`sw_p_stagger = { 4 }`
8. ✅ **关卡逻辑错乱**：
   - 主菜单选关号每帧夹到 `Save.MaxPlayable`（步数够但没通关时不会再显示成第 N 关）。
   - 领取步数后 `S.selectedLevel` 改用 `Save.MaxPlayable`（原来直接写 `data.unlocked`，会越级）。
   - 通关 Boss 后立刻把选关推进到新的可挑战关卡（标识不再停在旧关卡）。
   - 测试模式的怪物等级 ± 会同步主线进度（`unlocked` / `stageCleared`），农场（通关 2 关）和无尽（通关 10 关）跟着解锁。
9. ✅ **健康任务跨日锁死**：
   - `Save.RollDay` 对 `dayKey` 做校验：空串 / 格式异常 / 未来日期都按跨天重置，避免一整天卡在「已领取 / 已打卡」。
   - 无尽的每日结算与农场刷新各自 `pcall` 兜底，任意一边数据异常都不会把健康任务的每日重置带崩。
   - 挂机跨天时弹提示：昨天步数未领取会清零 / 健康任务已刷新。
10. ✅ **稀有种子买不了**：商店按钮下方直接写原因（今日买完 / 生息不足 / 具体解锁条件）。
11. ✅ **史诗 / 传奇种子买不了**：新增 `Farm.TierUnlockText`，声望商店与生息商店都显示该品级的解锁路径（例如「通关第 12 关解锁 或 声望商店累计消耗 2000 解锁」），不再只有一个灰按钮。
12. ✅ **公会贡献币排行榜**：改成取「累计获得的贡献币」`guild.total`（花掉不掉榜，不再受经验口径影响）。
