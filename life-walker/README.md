# 生命行者

> 把每一步，走成力量。

一款把**现实运动**和**俯视角动作 Roguelike**绑在一起的手机游戏。现实步数换算成金币与经验，金币用于养成，经验分配给职业升级；游戏内的关卡解锁也由当日步数决定。

当前版本：`v0.1.0`（剑客垂直切片）

---

## 已实现（v1）

### 主菜单
- 背景音乐：**当前整块关闭**（代码里 `AUDIO_DISABLED = true`）。移动端创建音频播放器会让测试客户端崩溃，所以连同桌面端一起关掉，音频文件也已从包里移除
  - 原方案是自己合成的钢琴版《卡农》（48kHz 单声道 16.8 秒循环），但听感不理想，后续换 AI 生成或授权素材再做
  - 循环要用 `Sound:SetLooped`（`SoundSource` 没有 looped 字段），重新启用时注意这一点
- 主菜单「设置」：背景音乐开关、0~100% 音量（点格子或 +/-）、当前状态速览（职业/等级/经验/金币/关卡/连续天数），设置写入存档
- 主菜单「设置 → 按键布局」：拖动摆放松杆 / 普攻 / 三个技能键 / 道具栏的位置，选中后可用「缩小 / 放大」调整大小，「重置」恢复默认，「完成」存入存档；战斗中立即生效
  - 摇杆模式：**按下即定位**（左半屏任意位置按下，摇杆就在那里出现，默认）或 **固定位置**
  - 拖尾跟随（默认开）：手指拖出摇杆范围时基座跟着走，摇杆头始终留在边缘，不会脱手
  - 死区 0.06 + 0.65 次幂曲线：轻推就有一半速度
  - 多指隔离：摇杆绑定按下它的那根手指，右手点技能/移开都不会打断左手移动
- 今日步数手动输入（−1000 / +1000），每日领取一次
- 步数 → 超静息消耗百分比 → 金币 / 经验双份产出
- 金币、经验、技能点、连续健康天数、当前职业等级
- 主菜单「角色」面板切换**剑客 / 枪客**，两个职业各自保存出战技能与等级
- **升级**：经验进「可分配经验」总池；点职业按钮选好给谁升级，再点「升级到 Lv.N」，直接从总池扣掉这一级需要的量（不再有「投入 / 全部投入」两步）
- 职业等级、升级门槛按每个职业独立；经验池、金币、关卡进度、连续健康天数、技能点仍是全局
- 经验升级（1→20 级，10→11 起需要连续健康 3 天，15→16 起需要连续健康 8 天）
- 连续健康 3 / 7 / 14 / 30 天奖励（金币 + 技能点）
- **关卡解锁双条件**：① 当日步数解锁到第 N 关（2000 / 8000 / 12000 三档）② 必须**打完第 N−1 关的 Boss**；两个条件同时满足才开放，主菜单会显示「已通关 X 关 · 可挑战 1 ~ Z」
- 开发模式按钮（`State.lua` 里 `dev = true` 时显示，正式发布改成 `false` 即整块隐藏）：下一天（推进虚拟日期）、测试模式（自选强化/技能/怪物直接进战斗）、**解锁关卡（直接开到 20 关）**、**经验 +1000**、**金币 +1000**、重置存档
- 测试模式仅本地可用，不会写入存档：可勾选任意专属/通用强化（右侧即时显示完整效果与需要携带的技能）、最多 3 个携带技能、按种类设置怪物数量（含 Boss）、**选择怪物等级 1~20**（右侧直接显示该等级的小兵血量/攻击，即对应第几关的数值），进入后不限波次
- 出战技能 3 格，点击打开技能选择面板，可自由搭配已解锁技能（支持交换）
- 主菜单「图鉴」：怪物、通用强化、职业专属、技能、状态与道具五个分页（内容随当前职业切换）
- 剑客专属强化 54 条（白 11 / 蓝 13 / 紫 15 / 金 9 / 彩 6）
- 枪客专属强化 44 条（白 9 / 蓝 9 / 紫 11 / 金 9 / 彩 6）
- 游侠专属强化 50 条（白 8 / 蓝 13 / 紫 15 / 金 7 / 彩 7）
- 法师专属强化 48 条（白 12 / 蓝 12 / 紫 10 / 金 8 / 彩 6）
- 专属强化只会出现在对应职业的奖励、商店与事件里，同名限一次；技能类条目还需要携带对应技能
- 通用强化新增：**镜面反射**（35% 概率把弹幕打回去）、**弹幕清除**（普攻击碎范围内子弹）、**轻身 / 疾风**（移速向）
- 移速整体上调约 8%（剑客 4.7 / 枪客 4.35 / 游侠 4.35 / 法师 3.9 米每秒），拉扯与躲弹更灵活
- **法师专属强化按元素过滤**：没带冰系技能就抽不到冰系强化（火/冰/电同理）；元素协调需要三系齐全、冰火两重天需要冰火同时携带

### 数值
- 小兵 HP `ROUND(25 × (1+(N−1)×0.2)^1.4)`，ATK `ROUND(5+(N−1)×0.9)`
- 精英 ×3.5 HP / ×1.8 ATK；Boss ×8 HP / ×2.5 ATK
- 房间倍率 `(1.12+(N−1)×0.0017)^(M−1)`，M 超过 9 按 9 锁
- 一关 4×4 地图，只能向右 / 上 / 下，终点右上角 Boss
- 房间等级按玩家走过的步数递增，路径越长约强

## 操作

| 平台 | 移动 | 技能 |
|---|---|---|
| 手机 | 左下虚拟摇杆 | 右下技能/平A键 + 上方道具键，均可点按 |
| 桌面预览 | WASD（支持八向） | J / K / L 技能，SPACE 平A，E 用道具，Tab 强化面板，也可直接用鼠标点按钮 |

## 如何启动（推荐）

双击项目根目录的 **`Play.bat`** 即可，始终运行 `scripts/` 里的最新代码，不需要构建。

- 游戏存档：`.cli/save.json`，删掉即重置进度
- 运行时：`.cli/UrhoXRuntime.exe`（不要直接双击，需要 cwd 和参数，`Play.bat` 已处理好）
- 想放桌面：右键 `Play.bat` → 发送到 → 桌面快捷方式

手动命令行等价于：

```bat
cd /d "<项目根>.cli"
UrhoXRuntime.exe main.lua "-tapcode_dir=<项目根>" -tool_mode -x 1280 -y 720
```

## 本地验证

运行时安装在 `.cli/`（已 gitignore），从 `.cli` 目录启动：

```bash
# 逻辑验证（无窗口）
cd .cli
./UrhoXRuntime.exe main.lua "-tapcode_dir=<项目根>" -tool_mode -graphicsheadless \
  -validate -validate-frames=60 -validate-timeout=30 \
  "-validate-output=<项目根>/.tmp/validate.json"

# 截图
cd .cli
./UrhoXRuntime.exe main.lua "-tapcode_dir=<项目根>" -tool_mode \
  "-screenshot=../screenshots/menu.png" -screenshot-frame=90 -x 1280 -y 720
```

`dev/` 里的脚本用于回归（直接从项目根运行 `dev/xxx.lua`）：
- `DevExp.lua`：全局经验池直接升级、扣量准确、职业独立、门槛拦截、旧存档（等级 / 已投入经验）迁移
- `DevRanger.lua` / `DevMage.lua`：游侠与法师的基础数值、资源、全部技能与元素连携
- `DevSkillRange.lua`：枪客 / 游侠 / 法师的技能范围提示形态、自动瞄准、蓄力指示、空放保护与三职业长跑
- `DevJoystick.lua`：自绘摇杆的方向、死区、松手清零、推动角色与区域外不吃输入
- `DevKbLayout.lua`：按键布局的默认值、拖动、边界夹取、缩放、重置、存盘与战斗内生效
- `DevMageElements.lua`：法师强化按携带元素过滤（全冰/全火/全电/三系各一的可用性、通用条目、需求文案）
- `DevPauseStatus.lua`：战斗暂停（开启/输入清空/暂停时不可攻击/恢复）、选关状态面板、测试模式怪物等级
- `DevStageGate.lua`：关卡双门槛（步数 ∩ 已通关+1）、旧存档迁移、Run.Start 拦截、Boss 通关记录、调试解锁
- `DevTesterFeedback.lua`：测试反馈 10 条逐项验证（退出测试、冲刺方向、反弹/消弹、枪势范围、精英奖励、移速、挫裂反馈）
- `make_font_subset.py`：重新裁剪中文字体（**每次新增中文文案后必须重跑**，否则新字没字形）
- `check_meta.py`：构建前检查资源 .meta —— uuid 含 `+` / `/`、孤儿 meta、uuid 重复（`+` 会被 CDN 解码成空格导致 404，社区踩过的坑），有问题退出码 1
- `DevNewBuffs.lua`：游侠 50 条、法师 48 条专属强化全量授予与长跑
- `DevMonsters.lua`：脓肿岩行者 / 疫蚀石魔 / 瘟衰巨像机制、测试模式投放与第 7 关后的正常刷新
- `DevSettingsView.lua`：设置面板（音乐开关 / 音量 / 状态）截图
- `DevSpear.lua`：枪客基础数值、三段普攻 / 枪势 / 六个技能的机制断言
- `DevSpearBuffs.lua`：44 条枪客专属全量授予 + 900 帧长跑 + 技能依赖过滤检查
- `DevSpearView.lua` / `DevClassMenu.lua`：枪客战斗与主菜单职业切换截图
- `DevEffectCheck.lua`：逐个验证专属强化的实际效果（剑气、剑影复刻、充能、格挡刷新、震波、减伤叠盾、护盾超限）
- `DevTestLab.lua` / `DevTestLabView.lua`：测试模式的自选强化 / 技能 / 怪物与面板排版
- `DevEffectView.lua` / `DevClassView.lua`：剑气波 / 剑影 / 强化面板的可视截图
- `DevBuffApply.lua`：逐条校验强化数值是否真正写进角色属性（攻击/攻速/移速/生命/护盾/暴击/吸血/CD）
- `DevClass.lua`：授予全部 54 条剑客专属强化，连续施法 / 击杀 / 连携的长跑冒烟
- `DevFlow.lua`：从起点走到 Boss，验证房间流程与解锁
- `DevEconomy.lua`：步数结算、连续奖励、升级
- `DevBoss.lua` / `DevShock.lua` / `DevWalls.lua`：Boss、冲击波分段、墙体生成
- `DevRewardClass.lua` / `DevShopClass.lua` / `DevCodex.lua` / `DevClassView.lua`：专属强化的奖励、商店、图鉴、战斗面板排版截图

## 字体说明

`assets/Fonts/MiSans-Regular.ttf` 目前是 **Windows 宋体/黑体占位**（SimHei，约 9.7MB），仅用于本地开发预览，不能用于正式发布。上线前请替换为已获授权的 MiSans 或其它商用中文字体。
