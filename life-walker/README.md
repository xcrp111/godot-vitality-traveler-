# 生命行者

> 把每一步，走成力量。

一款把**现实运动**和**俯视角动作 Roguelike**绑在一起的手机游戏。现实步数换算成生息与经验，生息用于养成，经验分配给职业升级；游戏内的关卡解锁也由当日步数决定。

当前版本：`v0.1.0`（剑客垂直切片）

---

## 最近更新汇总（2026-10-29 ~ 11-07）

这一轮主要做了五件事：**农场从零做出来并换成实景地图**、**加了一套云端排行榜**、**补了冥想音乐**、**把敌人寻路换成了真正的 A\***、**集中修了枪客 / 游侠 / 健康行为 / 果实的一批测试反馈**。

### 一、农场系统（单机版，新做）

- **9 种作物**：火灵果 / 冰晶草 / 雷击木 / 生息花 / 生命之花 / 彩虹蘑菇 / 时空藤 / 混沌花 / 凤凰花，按现实时间 4~24 小时成长，分发芽 / 生长 / 成熟三阶段
- **玩法**：种植、浇水（-15 分钟，2 小时冷却，每日 20 次）、超级水壶、一键浇水（声望 Lv.2）、收获（每种果实最多存 30 个）
- **果实 Buff**：最多携带 3 种，开局消耗 1 个并在本关生效（攻击 / 护盾 / 冷却 / 生命 / 血尘 / 随机强化 / 复活等）
- **声望**：浇水 +1、收获 +5，每日上限 50；声望商店卖种子 / 水壶 / 土地解锁券，4 → 9 块地
- **种子来源**：精英 8% / Boss 5% 掉落、每日 3 场战斗奖励、无尽每周 10 层奖励、两个商店
- **实景地图**：整张农场底图铺底（1400×941），9 块地按实测坐标叠加，未开垦压暗、成熟金色描边，操作放底部浮层

### 二、云端排行榜（异步联机第一步）

- 用 `clientCloud` 做四个榜：**无尽层数 / 关卡进度 / 农场收获 / 公会贡献**
- 45 秒缓存、30 秒上传节流、数值没变不上传；昵称走 `GetUserNickname` 并配了常用汉字昵称字体
- 离线 / 未登录自动降级，界面上会给出诊断信息，不影响单机玩法

### 三、听觉

- **冥想音乐**：原创手碟环境音（62 秒循环），分解和弦 + 滚奏式演奏，进入冥想时主 BGM 压到 12%、冥想音乐淡入 80%
- 背景音乐仍是钢琴版卡农，跟随设置里的开关与音量

### 四、战斗与敌人

- **敌人寻路**：换成 24px 网格 A\*，每 0.45 秒重算 + 视线拉直，角色站在墙对面时怪物会绕过来而不是贴墙打转（追踪型与远程型都走同一套）
- **游侠狙击**：箭固定从按下技能的位置射出，不再跟着跑位漂移
- **枪客 8 条反馈**：突刺收尾必叠失衡、铁枪固守收尾补挫裂、不动如山加强（失衡上限 +1）、三连循环文案、双重突刺 / 破军改「充能 +1」、虚影回响按技能形态复刻（掷枪会真的扔枪、三段枪式分三段）、飞枪破阵改为无限贯穿、回马震阵猎痕概率 20% → 45%

### 五、修复与调优

- **早睡加成看不见**：主菜单「预计 +N 经验」现在包含早睡奖励
- **健康行为**：冥想 CDR 可与其它减 CD 叠加、起身活动时长显示修正、未满 30 秒不能领奖
- **货币文案**：金币 → **生息**，银币 → **血尘**（存档字段不变）

### 近期数值修正
- **畸变疫病三怪调整**：脓肿岩行者（小兵）的感染 DPS 0.8→0.45 倍攻击、脓水 0.4→0.22 倍并收小范围；地面效果（脓水/腐液/衰竭疫域）改成按类型上色 + 呼吸脉动 + 内圈冒泡，一眼能看出踩没踩进去；玩家头顶状态栏新增「感染 / 衰弱 / 坏死」图标与倒计时；**瘟衰巨像的衰竭疫域改成技能**——每 7 秒开启 3 秒（狂暴后 5 秒一次、范围 180→220），关闭期间没有减速和掉血，近战有明确的输出窗口
- **关卡解锁修复**：「记录步数并领取」原来每天把步数档位**累加**到 `unlocked`，领几天就能刷到 20 关全开。现在按当日步数档位算（2000 / 8000 / 12000 → 开 2 / 3 / 4 关），并且仍要求通关上一关；只有开发模式的「解锁关卡」按钮会直接全解锁
- **回马枪动作**：角色先**向前冲出 120 距离**（可见位移）→ 刺中 → 顿 0.14 秒 → 再向后撤 140 距离；判定与地面提示都跟着新节奏走
- **位移技能全程无敌**：闪影突进、瞬影连斩、突刺奔袭、疾退腾挪、掠袭换位在位移/冲刺过程中免疫伤害（原来突刺奔袭要特定词条才无敌，撞上去会白吃伤害）。回马枪**不在此列**——它是刺出去再退回来、不靠穿怪打伤害，位移段正常吃伤害
- **回马枪判定**：后撤、前刺、地面提示改为共用「施法瞬间的朝向快照」，中途推摇杆不会再让两段错位；提示圈画在突刺真正落点的位置
- **死亡判定**：护盾吸收/减伤会留下 1e-16 级残血，血条显示 0 却永远不死；现在伤害低于 0.5 直接抹平，血量低于 0.5 直接判死
- **吸血**：单次回血上限从「伤害的 50%」改为「本次伤害的 100%」，多目标仍可各回各的；**紫色全局吸血 18% → 6%、金色吸血 5% → 10%**（原来紫的比金的还强）；新增普攻吸血 / 技能吸血两个独立词条位
- **鬼剑术**：满层剑意普攻改为远程拔刀剑气并**清空剑意**（之前不清层，可以连放 3 次）；满层不再触发剑气爆发
- **断势重击 + 小幅震荡**：第三段改为「近战判定 + 剑气波 + 击退」同时生效，不再互相顶掉（贴脸也能吃到第三段）
- **摇杆拖尾跟随**：跟随强度从 1:1 降到 0.18，并且基座相对按下点最多漂半径的一半（原来手指一拖摇杆就飞出去，方向手感会飘）
- **瞬影连斩**：第一段短促（0.10 秒）、段间约 0.2 秒停顿、第二段更重更亮（拖尾变亮 + 起手震屏），两段区分得开
- **闪影突进**：点按立即释放（自动朝向最近敌人/输入方向），**拖动即可选方向**（不等 0.22 秒长按），偏移不超过 20px 视为点按
- **剑心护体等状态**：HUD 新增状态图标条，显示剑心护体 / 格挡 / 铁枪固守 / 三段枪式 / 精准速射 / 狂暴 的剩余秒数
- **熔岩之心（法师紫）**：余烬地面原来会在每次 tick 时再次触发「火系命中」，导致余烬指数级自我繁殖、瞬间秒杀 Boss。现改为：余烬不再触发火系命中、最多同时 6 片、单跳伤害 0.15 → 0.12 倍攻击
- **精英不再回血**：打完精英掉血尘，回血 6% 的效果已按测试反馈移除
- **卸势格挡重做**：1 秒内完全免伤（可连续挡下多次攻击）；格挡时横剑架势 + 呼吸盾弧，成功格挡有强闪光、震屏、粒子；成功立刻反击一道 0.9 倍剑气，并获得 1 层剑意、让其他技能冷却 -0.8 秒
- **金色「破甲」修复**：原来写的是「普攻无视 30% 护甲」，但游戏里没有护甲系统、完全是无效词条。现改为「普攻伤害 +40%，普攻命中使目标受到的物理伤害 +8%（4 秒）」
- **彩色强化保底**：金色专属升级成彩色的概率 12% → 18% 起、每连一次 +7%，第 5 次必出；拿到彩色后计数清零。随机抽取时的彩色概率也从 4% 提到 6%（并随保底提高）
- **狂剑士**：技能掉血增加下限（不会低于 25% 最大生命），并自带 8% 吸血
- **回马枪**：后撤 46 → 60，前刺距离 110 → 170、扇形 70° → 85°，并补一段 52 的前突身位，撤完能立刻打到人
- **突刺奔袭**：时长 0.16 → 0.20 秒（更远），收尾加震屏/震环/叠失衡，不再像滑过去
- **猎影诱捕**：判定 70 → 46（视觉外框仍在），改为长按拖放指定落点；踩中的敌人被束缚 1.2 秒（不能移动）+ 减速 40% + 1 层猎痕；夹子改为锯齿夹颚模型
- **掠袭换位**：改为穿到目标身后落地并回头面对它；原来的「下一次普攻攻速 +12%」改成该次普攻伤害 +25%
- **箭影连射**：每支箭 0.6 → 0.85 倍伤害
- **枪客武器长度**：枪身从「基础射程 +22」缩到「基础射程 -4」，贴合实际判定，不再看起来能戳更远

### 无尽模式（新）
主菜单底部「无尽模式」入口，**主线通关第 10 关后解锁**（设计文档：无尽模式.docx）：
- **单层结构**：每层 3×3 共 9 个房间，起点走到 Boss 房，清掉 Boss 就进下一层，层数无上限
- **商店**：不要求每层都有商店房，但**任意相邻两层之间至少有一个带商店的层**（这一层没商店，下一层必定有）
- **测试**：「测试模式」面板里有「解锁无尽（测试）」开关（只改存档里的 dev 标记，不动真实主线进度）和「进入无尽（测试）」按钮，随手进去看新地图
- **强度**：等效主线关卡 = 层数 + 9。第 1 层 = 主线第 10 关，第 2 层 = 第 11 关……直接沿用主线的小兵/Boss 成长公式与房间倍率
- **强化上限 10 个**：满了以后每次战斗结算改成两步——先选 1 个新强化，再从已有里选 1 个丢掉的（可以取消）；数值会完整回退后再重算
- **推进**：生命、血尘、强化都带进下一层，每层开场回 20% 生命并补满护盾
- **记录**：历史 / 今日 / 本周 / 本月最高层数，破个人纪录给生息与经验，并把**记录勋章**升 1 级（最高 Lv.20）
- 排行榜目前只记本机成绩；联网的日 / 周 / 月榜单要等服务器就绪后再接

### 房间随机（伪随机，新）
主线和无尽的地图不再是固定模板，**每开局重新生成**，用的是「手工模板 + 受控扰动」而不是纯随机抽格子：
- **7 张主线手工模板**（标准路线 / 双商补给线 / 精英重压 / 事件旅路 / 轻战起步 / 双精英 / 商店绕行）+ **10 张无尽 3×3 模板**（6 张带商店、4 张不带），按关卡权重抽取
- **结构永远合法**：起点左下、Boss 右上、起点右边第一间是战斗房；主线每张图商店房与事件房至少各 1 个，无尽每层至少有 1 个事件房、商店按隔层规则保证（`Config.CheckMap` 校验，回归测试跑 200 次）
- **受控扰动**：45% 概率把某个商店房和某个事件房的位置对调，路线走向每局不同
- **难度归一**：算战斗房平均强度（轻战 0.6 / 标战 1.0 / 混战 1.4 / 精英 2.2 / 双精 3.0），比目标高就降级、低就升到混战为止；前 5 关不刷双精房
- 结果：每局地图不一样，但不会随机出「一关七个精英房」这种打不过的图；房间倍率仍按「进入的第几个房间」递增

### 健康任务（现实健康行为 → 游戏内收益）

## 字体说明

- 字体子集：`assets/Fonts/MiSans-Regular.ttf` 由 `dev/make_font_subset.js` 从 `dev/fonts/MiSans-Regular.full.ttf` 裁剪（只保留 scripts 里用到的字）。**新增中文文案后必须重跑**，否则新字显示成方框：
  `npm i subset-font --prefix .tmp/font-deps` → `NODE_PATH=.tmp/font-deps/node_modules node dev/make_font_subset.js`
- 不要用 fontkit 的 subset（生成的字体会缺 cmap 表，整个界面文字全废）

`assets/Fonts/MiSans-Regular.ttf` 目前是 **Windows 宋体/黑体占位**（SimHei，约 9.7MB），仅用于本地开发预览，不能用于正式发布。上线前请替换为已获授权的 MiSans 或其它商用中文字体。
